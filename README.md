# Half Online 線上策展

React + Vite 製作的線上策展網站，以全螢幕 scroll storytelling 呈現「在網路裡，卻不在身邊」的主題。

## Features

- GSAP ScrollTrigger pinned scroll 敘事動畫
- Lenis 平滑滾動
- Opening 畫面、日期、隨機語錄
- 音樂開關與頂部進度條
- Navbar section 編號導覽
- 已讀不回互動
- 官方平台：Instagram、Threads、LINE
- Podcast 與心理資源段落
- 手機與桌面滿版響應式版面

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

部署到 Vercel 或 Netlify 時：

- Framework: Vite
- Build command: `npm run build`
- Output directory: `dist`
